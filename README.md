# NeuroNexus

**Google Form Clone**
A lightweight, responsive web form that mimics the look and feel of Google Forms using only HTML and CSS (no JavaScript).

![image](https://github.com/user-attachments/assets/62a55765-74df-4aa8-9825-26873f4f2b84)

**Project Overview**
This project creates a professional-looking contact information form with a clean, modern UI inspired by Google Forms. It was built as a demonstration of frontend form development skills using only HTML and CSS.

**Features**

**Responsive Design**: Works seamlessly across desktop and mobile devices
**Google Forms-inspired UI:** Clean, modern aesthetic with Google's color palette
**Form Validation**: Uses HTML5 validation for required fields and input types

**Input Fields:**

Full Name (Text Input)
Contact Number (Phone Input)
Address (Multiline Textarea)
Company Name (Text Input)
Email Address (Email Input)
Department (Dropdown with options)
Gender (Radio Button selection)


**Enhanced UI Elements:**

Hover effects on the submit button
Contrasting background colors
Box-shadow for depth
Focus states for better accessibility
Required field indicators

**Technologies Used**

HTML5
CSS3
